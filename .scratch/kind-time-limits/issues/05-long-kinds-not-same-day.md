# 05 — 大题和写作题记了「忘了」之后,当天不再出现

Status: ready-for-agent

## Parent

`.scratch/kind-time-limits/PRD.md`

## What to build

大题和写作题记了「忘了」以后(超时或自己评都算),今天不再出现,明天再来。刚看完范文就马上重写一遍,
考的是短期记忆,不是回忆。其他题型照旧,当天还会再出现。

- 到期时间不早于下一个日界(次日凌晨 3 点),而且不再插回本轮队列。
- FSRS 和固定阶梯两套引擎都成立:先由引擎排期,再由计时规则模块调整到期时间。稳定性等其他排期结果不动。
- 评级后那一行显示的「下次」时间,和调整后的到期时间一致。
- 「学习更多」不拿今天已经记了「忘了」的大题和写作题,否则会把刚推到明天的卡又拿回来。
- 「回顾今日」照旧包含今天答过的所有卡(PRD 里的假设,用户可以推翻)。

## Acceptance criteria

- [ ] 计时规则模块:大题 / 写作题 + 忘了 → 到期时间不早于次日 3 点;其他题型、其他评级不受影响;两套引擎各测一遍(单元测试)。
- [ ] 学习页:写作题超时后,本轮不再出现;评级那一行显示的下次时间是明天;今日进度条把它算进「今天不再出现」。
- [ ] 「学习更多」取卡时跳过它们(用真 SQLite 测取卡语句)。
- [ ] 「回顾今日」仍然列出它们。
- [ ] 模拟器上手动验证,结果记在本 issue 的 Comments 里。
- [ ] 完整桌面测试台通过,ArkTS 构建成功。
